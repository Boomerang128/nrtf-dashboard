# NRTF Hybrid Dashboard (Phase 2)

Industrial IoT Analytics with Real-time Anomaly Detection.

## Features
- **Real-time Monitoring**: MQTT/WebSocket telemetry visualization.
- **AI Sentinel**: Isolation Forest anomaly detection (Pure Python).
- **Historical Insights**: Unified energy normalization and delta calculation.

## Quick Start
```bash
docker-compose up --build
```
